Codex として、実装前の計画を作成してください。ファイル編集は行わないでください。

既存コード、テスト、設定を読み、実装に必要な最小限の変更だけを計画してください。過剰な抽象化、互換性シム、将来用の拡張点は入れないでください。

Report Directory に過去のレビューがある場合は確認し、未解決の指摘が残らないように計画を更新してください。

計画には以下を含めてください。

- 要件の解釈
- 影響範囲
- 実装手順
- テスト方針
- 実行すべき検証コマンド
- リスクと未確定事項

未確定事項が実装判断を左右する場合だけ「ユーザー入力が必要」としてください。合理的に仮定できる場合は、仮定を明記して計画を進めてください。
