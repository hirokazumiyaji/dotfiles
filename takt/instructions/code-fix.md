3. 修正後、全テストが Green であることを確認する
4. ビルド（型チェック）が成功することを確認する

## git staging 管理

修正前に既存の変更を stage し、修正分が unstaged に溜まるようにする:

1. `git add -A` で現在の変更を全て stage する
2. 修正を実施する
3. `git diff` で unstaged の差分（= 今回の修正分）を確認する
4. 問題のある修正は `git checkout -- <file>` で取り消す
5. 良い修正のみ `git add <file>` で stage に追加する

## 原則

- 指摘された箇所のみ修正する。周辺コードの改善はしない
- 修正が不適切と判断した場合は、理由を明記して修正しない選択も可
- 新たなバグを導入しないこと
