Claude Code として実装をレビューしてください。ファイル編集は行わないでください。

レビューでは Claude Code の以下のスキルも使用してください。

1. `/simplify`
   - 編集は行わず、簡素化レビューとして使用する
   - 過剰な抽象化、不要なフォールバック、重複、責務の曖昧さを確認する
2. `/coderabbit:review`
   - CodeRabbit 風の包括レビューとして使用する
   - セキュリティ、バグリスク、品質、性能、テスト不足を確認する

参照するレポート:
- {report:plan.md}
- {report:implementation-report.md}

確認すること:
- 実装が計画とユーザー要件を満たしているか
- 不要な変更や計画外の挙動変更がないか
- バグ、例外処理漏れ、境界値漏れがないか
- テストが意味のある振る舞いを保護しているか
- 検証コマンドが実行され、結果が妥当か
- `/simplify` の観点で、より単純にできる修正必須の問題がないか
- `/coderabbit:review` の観点で、修正必須の問題がないか

修正必須の問題がある場合だけ REJECT としてください。REJECT では修正担当の Cursor が迷わないように、ファイル、問題、期待する修正を具体的に書いてください。

任意改善、好みの差、将来の拡張に備えた提案だけなら APPROVE とし、指摘事項には suggestion として分離してください。
